STEP 5 OF 18

Waiting for a decision

The plan

a patient asks for a code, it arrives by text, and with it they see only their own visits; 5 wrong codes pause sign-in for 15 minutes. STEP 10 OF 18

Release safely before collecting real patient data

Waiting for a decision
◎

The plan

after steps 4 and 5, show the clinic manager's supplied patient notice before collecting personal data. This also waits for the text-message service for reminders and patient sign-in codes. On isolated made-up records, restore a backup into a separate database and read the same visits back. Document the Docker release and return to the previous working image, including database compatibility; try the rollback on that isolated copy without losing its visits or overwriting live data. Give the release a version and a dated line in CHANGELOG.md, from the clinic's own git repository. Follow the README from an empty computer as another operator and check that only the IT lead can read audit records, expired audit records are removed at 90 days, and the public doctor list does not create protected-record audit events. These are checks to run, not claimed results.
