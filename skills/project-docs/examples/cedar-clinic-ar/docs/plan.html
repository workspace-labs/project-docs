بعد الخطوتين 4 و5، أظهر إشعار المرضى الذي يقدّمه مدير العيادة قبل جمع البيانات الشخصية. تنتظر أيضًا خدمة الرسائل النصية للتذكير ورموز دخول المرضى وقرار التعافي عند الإصدار. بسجلات مختلَقة معزولة، استعد نسخة احتياطية في قاعدة بيانات منفصلة واقرأ المواعيد نفسها. دوّن طريقة إصدار Docker وجرّب التعافي عند الإصدار المتفق عليه تحت TRD: أين يعمل على النسخة المعزولة، مع الإشارة ومن يقرر. لا تجرّب الصورة السابقة إلا إذا أمكنها قراءة المواعيد المحفوظة حديثًا. وإلا فجرّب البديل المتفق عليه. أعطِ الإصدار رقمًا وسطرًا مؤرّخًا في CHANGELOG.md، من مستودع git الخاص بالعيادة. اتبع README من حاسوب فارغ كمشغّل آخر وافحص أن مسؤول التقنية وحده يقرأ سجلات التدقيق، وأن السجلات المنتهية تُحذف بعد 90 يومًا، وأن قائمة الأطباء العامة لا تنشئ أحداث تدقيق للسجلات المحمية. هذه فحوص ستُجرّب وليست نتائج مدّعاة.
