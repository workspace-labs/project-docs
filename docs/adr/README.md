# Decision records

Why project-docs is built the way it is. Numbers are never reused. An accepted decision is never edited to
change it: a new record replaces it, and the old one names its successor.

| # | Decision | Status | Date |
|---|---|---|---|
| [0001](0001-one-skill-with-a-file-per-document.md) | One skill, with a file per document | Accepted | 2026-10-08 |
| [0002](0002-documents-live-in-docs-and-the-prd-is-the-scope.md) | The documents live in `docs/`, and the PRD is the scope | Accepted | 2026-10-08 |
| [0003](0003-an-html-preview-page-shows-the-looks.md) | An HTML preview page shows the looks | Accepted | 2026-10-08 |

A new record starts as **Proposed** and becomes **Accepted** only on the owner's word. Other statuses:
Rejected, Deprecated, Superseded by NNNN.
